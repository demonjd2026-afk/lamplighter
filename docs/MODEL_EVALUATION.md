# Model evaluation

Generated by `python -m eval.model_eval` on 2026-11-24. Inputs are 5 incidents recorded from the demo shop (`eval/fixtures/incidents.json`).

The model never decides anything in Lamplighter. It writes prose for the postmortem, and that prose passes a filter before anyone sees it. This page measures the filter, and then the model behind it.

## 1. Guard benchmark (offline, deterministic)

Sentences built from the recorded evidence, then corrupted in a known way. The filter must keep the faithful ones and drop the rest.

| Input | Cases | Expected | Handled correctly |
|---|---|---|---|
| faithful | 69 | keep | 69/69 |
| citation does not exist | 69 | drop | 69/69 |
| one real and one invented citation | 69 | drop | 69/69 |
| no citation | 69 | drop | 69/69 |
| number changed | 59 | drop | 59/59 |
| number borrowed from other evidence | 59 | drop | 59/59 |
| malformed item | 25 | drop | 25/25 |
| false claim with no number (known limit) | 20 | drop | 0/20 |

**Fabrications the filter is built to catch:** 350/350 dropped. **Faithful sentences:** 69/69 kept.

**Known limit:** 20/20 false claims that contain no number and cite a real evidence id pass the filter. It checks citations and numbers, not meaning. That is why the narrative is labelled as model-written, is never used as an input to a decision, and why the judge below exists.
